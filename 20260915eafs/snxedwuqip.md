# 深圳做三代试管要准备什么？得准备多少钱？

> 更新时间：2026-09-15 (UTC+8)

一、深圳做三代试管要准备什么?

1. 手续与证件

身份证：夫妻双方需提供有效的身份证原件及复印件。

结婚证：证明夫妻关系的合法性，需提供原件及复印件。

计划生育服务证或相关证明：符合国家的计划生育。

签署知情书：明确试管婴儿治疗的相关风险及后续安排。

2. 身体检查

血常规、尿常规、肝肾功能等常规检查。

性激素六项、传染病筛查、染色体检查等专项检查。

评估生育能力，确定是否适合进行三代试管婴儿。

3. 心理准备

了解试管婴儿技术的原理、流程及可能的风险。

保持积极乐观的心态，增强信心。

寻求专业心理医生的帮助和支持，缓解焦虑和压力。

4. 生活调整

保持良好的生活习惯，如规律作息、健康饮食等。

避免接触有害物质，如辐射、化学物质等。

适当运动，提高身体素质。

二、深圳做三代试管得准备多少钱?

深圳三代试管婴儿的总费用大致在3-8万元人民币之间，具体费用因个体差异和医院选择而有所不同。以下是详细的费用明细：

1. 术前检查费用

夫妻双方全面的身体检查费用，通常在数千至数万元人民币之间。

2. 促排卵药物费用

药物费用因药物种类(国产或进口)和用药方案而异，大致在数万至数万元人民币之间。

3. 试管手术相关费用

取卵手术、胚胎培养、胚胎筛选(如PGS/PGD)及胚胎移植等费用，加起来可能在数万元人民币左右。

4. 其他费用

如黄体支持药物费用、血液HCG检测费用、B超检查费用、胚胎保存费、冷冻胚胎复苏费等，这些费用因人而异，但通常也会占据一定的比例。

三、如何省钱做三代试管?

1. 选择合适的医院

深圳的公立医院通常费用较低，且技术水平高。

私立医院虽然服务可能更加个性化，但费用相对较高。

咨询多家医院，了解费用明细和成功率，选择性价比高的医院。

2. 对比药物价格

促排卵药物是一个大的支出点。

了解并对比不同品牌和进口与国产的药物价格，选择性价比高的药物。

3. 合理规划治疗次数

与医生沟通个人情况，根据成功率和个人经济状况合理规划治疗次数。

多次低剂量的治疗有时比单次高剂量的治疗更经济。

4. 利用医保

关注深圳地区的医保，了解是否包含辅助生殖项目。

如果符合条件，利用医保减轻经济负担。

总之，在深圳做三代试管需要准备的事项和预算范围相对明确。
