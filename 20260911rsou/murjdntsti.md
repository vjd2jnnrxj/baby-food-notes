# 什么是试管婴儿微促？附价格明细表！

> 更新时间：2026-09-11 (UTC+8)

微促用简单的话怎么来形容？

“微促”是微刺激促排卵的简称，这个方案是相对于传统长方案、短方案等“大促”而言的形容，采用小剂量药物和温和的促排手段，经过几个月和几个周期进行，每次周期获得数量较少但平均质量更高的卵子，从而得到更好质量的胚胎。

微促有什么好处你知道吗？

1. 相对于传统大促对身体负担小，使用激素而造成的身体不适感明显减轻，减少卵巢过度刺激的风险，也降低远期的妇科风险。

2. 促排卵过程更轻松，在促排卵时不需要全身麻醉，流血少，术后恢复非常快。

3. 微促不过度透支卵子，每个月可以连续做，每次取得个数少但平均质量更优的卵子，对身体的伤害减少，而大促每次促排之间要间隔三个月，而且不建议超过6次。

4. 对于大龄、卵少、卵巢功能差的患者而言，微促虽然速度慢，一般来说累计3-5个周期都可以获得足够好的胚胎，保证移植的成功率。

与传统大促有什么不同呢？

1、微促使用的激素量更少

两种方案使用的促排卵针剂的剂量，微促用量更少，而大促用量更多，刺激性更大。

2、微促对卵巢负担更小

卵子生长期分为卵泡募集期和优势卵泡生长期，大促是从募集期开始打针到排卵期，而微促是在募集期口服药物微量促排，由于促排启动时间的不同，微促基本上使用的就是身体本次周期自然发育的卵子，每个月可以连续做，对卵巢的负担很小。

3、微促通过多次促排卵来累积胚胎

微促每次取得卵子的个数虽然比较少但平均质量更优，而且每个月都可以连续做，累计3-5个周期就可以得到足够好的卵子吗，从而得到质量好的胚胎保证移植的成功率。

所以在治疗过程而言，微刺激就像把这段时间的短跑变成了长跑，需要更多的耐心和努力，但是有氧运动对身体也更好，而且对于卵子储备少或高龄女性而言，微刺激可以帮她们成为妈妈。
